Storybook's day-one workflow has five moves. First, add Storybook to an existing project with `npx storybook@latest init` — the automigration detects your framework (React, Vue, Angular, Svelte, Web Components), generates a `.storybook/` config directory, and scaffolds example stories. Then `storybook dev -p 6006` opens the workshop in your browser while your app keeps running on its own port.

Second, co-locate a story file next to the component: `Button.tsx` gets a sibling `Button.stories.ts`. The file's default export is the meta object — a `title` like `Button` (which builds the sidebar hierarchy, e.g. `Form/Button` nests it) and the `component` reference that unlocks autodocs and automatic Controls. Every named export after that is a story, and each story captures exactly one state: `Primary`, `Secondary`, `Disabled`, `Loading`, `Error`.

Third, parameterize states with args instead of copy-pasted renders. A story's `args` object becomes the component's props, and `argTypes` declared once in meta tell Controls how to edit each prop — a toggle for booleans, a select for enums, a slider for numeric ranges. Because meta owns the arg contract, adding one new story for a new state costs just a few lines.

Fourth, add depth when isolation is not enough. Decorators wrap stories with the providers a component expects (theme, router, data store). Parameters attach per-story or global configuration such as viewports and chromatic ignore rules. For states that only exist after interaction — a modal opening, a form validating — write a `play` function that scripts `userEvent` clicks and assertions, and the story becomes both a demo and a test.

Fifth, ship the loop into CI. `storybook build` produces a static site you can publish (e.g. to Chromatic or any CDN) so every branch gets a reviewable URL. The test runner executes every story and its play function headlessly in Playwright or Puppeteer, and visual regression snapshots diff pixels between commits. The payoff: the same story file drives development, documentation, and the release gate — one artifact, three jobs.
