# Teaching Concepts in Software Docs

Help users understand the ideas behind a web app, not just the clicks: mental models, analogies, worked examples, interactive explanations and checks that make it stick

## Start
* [Teaching Concepts in Software Docs](sections/intro/section.md) — topic briefing and roadmap

## Why Concepts Matter
* [Steps vs Understanding](sections/knowledge-kinds/section.md) — Procedural knowledge is knowing the steps; it breaks as soon as the user's situation differs from the documented one
* [Three Models of the System](sections/mental-models/section.md) — Don Norman distinguishes the designer's model (how the designers think it works), the system image (the UI and the docs) and the user's model (what users believe)
* [Why Concepts Check](sections/quiz-why/section.md) — Starter quiz section.

## Techniques for Explaining
* [Explaining Techniques](sections/concept-techniques/section.md) — An analogy links a new idea to one the user already knows (a workspace is like a shared drive folder), and a good one says where it breaks down
* [Explain 'Permission Inheritance'](sections/explain-workshop/section.md) — Cognitive load: working memory holds only a few new items at once, so introduce a few new concepts at a time and build on them
* [Anatomy of a Concept Page](sections/concept-page/section.md) — A concept page opens with a one-sentence definition in plain words, then says why it matters to the user
* [Techniques Check](sections/quiz-techniques/section.md) — Starter quiz section.

## Interactive Explanations
* [Kinds of Interactive Explanation](sections/explorables/section.md) — Explorable explanations (a term popularised by Bret Victor) let readers change inputs and watch the idea respond, instead of only reading about it
* [Predict → Observe → Explain](sections/poe-loop/section.md) — Predict-Observe-Explain (POE): the learner predicts what will happen, observes the real outcome, then explains any difference
* [Build a POE Moment](sections/order-poe/section.md) — Starter reflection-sequence section.
