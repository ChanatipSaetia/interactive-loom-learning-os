# AI Agent Capability Taxonomy

A browsable taxonomy of AI agent capabilities organized by functional category.

## Data Files

* `hierarchical-orchestration.yaml` — Sub-agents managed in a tree structure
* `memory-context.yaml` — Short-term and long-term memory systems
* `peer-collaboration.yaml` — Agents communicating as equals
* `reasoning-planning.yaml` — Step-by-step reasoning and task decomposition
* `self-evaluation.yaml` — Agents that critique and improve their own output
* `sequential-choreography.yaml` — Pipelined agents passing work downstream
* `supervisor-router.yaml` — A central coordinator delegating to specialists
* `tool-use.yaml` — External tool invocation and API integration
