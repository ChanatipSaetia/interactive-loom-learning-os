# Technical Writing for Software Docs

Write web app manuals that users can find, follow and trust: the right kind of page, steps that work, plain language and a review loop

## Start
* [Technical Writing for Software Docs](sections/intro/section.md) — topic briefing and roadmap

## Four Kinds of Docs
* [The Diátaxis Framework](sections/diataxis/section.md) — A tutorial is learning-oriented: it guides a beginner through a safe, guaranteed-to-work lesson, like a driving lesson
* [The Diátaxis Compass](sections/doc-type-compass/section.md) — The Diátaxis compass asks two questions: is the content about action (doing) or cognition (knowing), and does it serve acquisition (study) or application (work)?
* [Doc Types Check](sections/quiz-doc-types/section.md) — Starter quiz section.

## Writing Steps That Work
* [Anatomy of a Task Page](sections/task-anatomy/section.md) — Title a task page with the user's goal as a verb phrase, such as 'Export a monthly report', not the feature name
* [UI Text Conventions](sections/ui-conventions/section.md) — Write UI labels in bold, spelled and capitalised exactly as they appear on screen
* [Page Rewrite Workshop](sections/page-rewrite/section.md) — Screenshots help readers find hard-to-spot controls but go stale every release, so use them only where text alone isn't enough
* [Assemble a Task Page](sections/order-task-page/section.md) — Starter reflection-sequence section.
* [Task Writing Check](sections/quiz-task-writing/section.md) — Starter quiz section.

## Style & Plain Language
* [Plain Language Rules](sections/plain-language/section.md) — Keep sentences short, aiming for an average of about 15–20 words
* [Style Guides & Tools](sections/style-guides/section.md) — The Microsoft Writing Style Guide is a free public guide covering voice, UI text and terms for software docs
* [Readability Calculator](sections/readability/section.md) — Flesch Reading Ease = 206.835 − 1.015 × (words per sentence) − 84.6 × (syllables per word); higher scores are easier to read
* [Style Check](sections/quiz-style/section.md) — Starter quiz section.
