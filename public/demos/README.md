# User Journey design prototypes

These standalone pages preserve early design experiments from the User Journey implementation:

- `motorcycle-user-journey.html`: initial experience walkthrough, with Read and Present controls.
- `simple-user-journey.html`: editable two-component authoring prototype, with motorcycle and AI examples.
- `*-journey-prototype.oui`: the examples used by the authoring prototype.

The current implementation is the native `user-journey` section in Loom Viewer and Studio. Its demo is `public/content/user-journey-demo/`, also available as `samples/user-journey-demo.loom.oui`. The historical pages do not track the current presentation styles or runtime behavior.
