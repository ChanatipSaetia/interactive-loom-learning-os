Interactive Learning OS

Learn how to bundle and load interactive learning sections via CDN links, and explore a live-rendered curriculum on LangGraph state machines.

How to load Loom Sections

You can choose to load the section data dynamically from a local JSON file (cleaner separation) or embed it inline directly inside your HTML. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Loom Learning App (Local JSON)</title>
  <!-- Load Loom Sections CSS Library -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/loom-learning-sections@1.0.7/loom-sections.css">
</head>
<body style="background-color: #232634; color: #c6d0f5; font-family: sans-serif;">
  <div id="loom-root"></div>

  <!-- Load Loom Sections Javascript UMD Bundle -->
  <script src="https://cdn.jsdelivr.net/npm/loom-learning-sections@1.0.7/loom-sections.umd.js"></script>
  <script type="module">
    try {
      // 1. Read the JSON file created in the same folder
      const response = await fetch('./langgraph.json');
      if (!response.ok) throw new Error('HTTP error ' + response.status);
      const sections = await response.json();
      
      // 2. Render sections with optional title + theme
      LoomSections.render(document.getElementById("loom-root"), sections, {
        title: "My Learning Topic",  // rendered as a header above sections
        theme: "frappe",             // built-in: "frappe" | "latte" | "mocha" | "macchiato"
      });
    } catch (err) {
      console.error('Failed to load JSON file:', err);
    }
  </script>
</body>
</html>
Setup instruction: Create a file named langgraph.json in the same folder as your HTML file. Load the page via a local HTTP server (like npx serve . or python3 -m http.server) to avoid CORS browser blocks on file:// protocol. 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Loom Learning App (Embedded)</title>
  <!-- Load Loom Sections CSS Library -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/loom-learning-sections@1.0.7/loom-sections.css">
</head>
<body style="background-color: #232634; color: #c6d0f5; font-family: sans-serif;">
  <div id="loom-root"></div>

  <!-- Load Loom Sections Javascript UMD Bundle -->
  <script src="https://cdn.jsdelivr.net/npm/loom-learning-sections@1.0.7/loom-sections.umd.js"></script>
  <script>
    const okfSections = [
      {
        "type": "text",
        "props": {
          "title": "Welcome",
          "paragraphs": ["# Welcome to Interactive Learning\nThis page loads sections via embedded inline JS!"]
        }
      }
      // Add other sections here...
    ];
    
    // Render sections with optional title + theme
    LoomSections.render(document.getElementById("loom-root"), okfSections, {
      title: "My Learning Topic",  // rendered as a header above sections
      theme: "mocha",              // or pass a token map: { "--ctp-base": "#1e1e2e" }
    });
  </script>
</body>
</html>
Prototyping hint: Best for offline testing, single standalone HTML files, or environments without a static file server. However, it mixes structure (HTML) with curriculum data (JSON).
