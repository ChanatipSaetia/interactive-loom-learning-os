## Summary of Decisions

- **Map Topology Storage (Q1):** Stored declaratively in `public/hexmaps/<topicId>.yaml`, loaded by storage adapters, and validated by the Validation Gateway (Tier 2 Zod + Tier 3 semantic reachability).
- **Section Encounter Ingestion (Q2):** Encounters dynamically mount real Core Sub-Context section components inside the Gamification view, evaluating gameplay outcomes via the standardized Section Result Contract (`onResultChange` / `onEvent`).
- **State Persistence (Q3):** Dual-tier persistence isolating Global Character Profile (`loom_gamification_global_profile`) across topics from ephemeral per-topic campaign state (`loom_gamification_campaign_<topicId>`).
- **Timed Reflection Magic Decryption (Q4, Q9):** Active floating `<RunicCountdownRing>` with live rune decryption particles and timeout penalties.
- **Sanctuary Healing (Q5, Q11):** Floating `<SanctuaryTickMonitor>` inside reading drawers with 10s progress ring, floating healing particles (`+10 HP`), and visit decay counters.
- **Autonomous Trade-off Buff & Vulnerability Synthesis (Q6, Q12):** Reactive `<TradeoffStatPreviewBar>` with live buff/vulnerability badges and artifact forging.
- **Boss Battle & Combat Stage (Q7, Q10):** Animated `<CombatStageHeader>` displaying live Player vs Enemy HP, floating hit numbers, and interactive Key Item skill triggers (`Adapter Shield`, `Port Blade`).
- **Encounter Viewport & Navigation (Q8):** Smooth canvas pan/zoom into target node with an expandable, glassmorphic Docked Bottom Drawer (`<EncounterDrawer>`).
