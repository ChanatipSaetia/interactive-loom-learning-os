## [2026-06-01 00:45] Issue #9 Complete
- What was built: Node dragging (mouse + touch) and zoom/pan (wheel zoom, drag-to-pan, pinch-to-zoom) for the flowchart SVG component. Nodes can be dragged to reposition; connected edges follow in real-time. Drag positions are session-only via useState (no localStorage/persistence). Zoom uses SVG viewBox scaling via a transform `<g>` wrapper. Pan works on SVG background clicks. All state resets on page reload.
- Tests added: 4 unit tests (transformable canvas group, node mouse handlers, node touch handlers, SVG pan/zoom handlers) + 6 E2E tests (drag node edges follow, session-only reset on reload, wheel zoom, drag-to-pan, mobile viewport zoom, aspect ratio preservation)
- Learnings: Playwright's `dragTo` fails when the drag destination is outside the original element bounds — use raw `page.mouse` events instead. SVG coordinate conversion via `getScreenCTM().inverse()` requires storing the SVG element reference in a ref to avoid stale DOM queries. Transparent SVG `<rect>` for background capture must be before interactive elements in render order to avoid intercepting pointer events during Playwright dragTo. `getAttributeSync` doesn't exist in Playwright — use async `getAttribute()`.
