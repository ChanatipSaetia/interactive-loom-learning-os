# Issue Tracker

This repo uses **GitHub Issues** for issue tracking.

## Remote

- **URL:** https://github.com/ChanatipSaetia/interactive-loom-learning-os
- **CLI:** `gh` (GitHub CLI)

## Conventions

- Issues are created via `gh issue create` with title, body, and labels.
- When breaking down work, create one issue per independently-grabbable unit (tracer-bullet vertical slice).
- Issue body should include acceptance criteria as a checklist.
- Link issues to PRs with `closes #N` or `fixes #N` in the PR body or commit message.

## For skills

- `to-issues`: Use `gh issue create` to create issues on GitHub.
- `triage`: Use `gh issue edit <n> --add-label <label>` to apply triage labels.
- `to-prd`: Publish the PRD as a GitHub Issue (epic/milestone issue).
