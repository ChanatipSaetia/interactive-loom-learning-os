## Q3: AI Error Diagnostics Payload & Output Interface

**Q:** How should validation errors be structured and reported so that an AI agent can parse the report and fix the issue accurately without human intervention?

**A:** Structured Machine-Readable JSON with Remediation Hints & Context via CLI (`npm run okf:validate [--json]`) and exported JS function (`validateTopic`).

**Decision:** Errors will be reported as structured JSON containing `file`, `topicId`, `sectionName`, `tier`, `field`, `line`/`column`, `message`, and `fixHint` (with context/valid alternatives), callable via `npm run okf:validate` script and programmatic JS API.
